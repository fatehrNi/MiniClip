# 隐私说明

## 数据在哪里

全部在程序旁边的 `data\` 目录（便携布局，不写 C 盘）：

```
data\index.log      元数据：时间、来源程序、窗口标题、大小、重复次数、格式清单、哈希、预览
data\content.log    正文（文本内容原样保存）
data\images\        复制过的图片内容（PNG，文件名是内容哈希）
data\media\         音频与图片文件快照（WAV/MP3/PNG…，同样按内容哈希去重）
data\config.txt     配置
data\trace.log      仅 --trace 时：环节耗时
data\crash.log      仅出错时：异常堆栈
data\pid.txt        运行实例的进程号（`--stat` 用），退出即删除
```

用 `MINICLIP_DATA` 环境变量可以把数据改到别处；只有程序目录不可写时才退回
`%LOCALAPPDATA%\MiniClip`。

## 会不会上传

不会。程序不监听网络、不发起任何请求，也没有内置更新检查。
唯一的对外动作是：托盘菜单"打开数据目录"会调用 `explorer.exe` 打开本地文件夹。

## 敏感内容怎么办

密码管理器（1Password、KeepassXC、浏览器隐私模式等）通常会临时关闭剪贴板链或写入后即清除，
这类内容一般采不到；但不能保证。请把三点当作使用前提：

1. `data\` 里是你复制过的原文，**没有加密**。磁盘未加密的机器上，能读到这个文件夹的人就能读到历史。
2. 需要临时不记录：托盘右键 → **暂停记录**（`Ctrl+Alt+V` 唤出面板后按 `Ctrl+P` 可置顶重要条目，`Del` 删除单条）。
3. 需要清空：托盘右键 → **清空历史**（保留置顶项）；彻底清除请退出程序后删除整个 `data\` 目录。

## 提 issue / 反馈时

关于框里的"复制诊断信息"只包含版本号、配置、条目数、内存占用和系统版本，**不含任何复制内容**。
如果你打算附上 `index.log` 或 `content.log`，请先自己检查并删掉敏感条目——这两个文件里有原文。
